# WORLDIA

スマートフォンとPCで遊べる、4つの運営シミュレーションを収録した静的Webゲームです。

## 収録モード

- 小さなお店経営
- フェス・ライブ運営
- 街づくり
- 国家運営

データはゲームごとにブラウザへ自動保存されます。PWA対応のため、一度読み込んだ後はオフラインでも起動できます。

## 起動

ES ModulesとService Workerを使用するため、ローカルサーバー経由で開いてください。

```bash
python3 -m http.server 8080
```

その後 `http://localhost:8080` を開きます。GitHub Pagesではそのまま公開できます。
