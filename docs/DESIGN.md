# WORLDIA 全体設計

## 基本方針

- 各モードは独立した状態と進行単位を持つ。
- 共通の保存、イベント、UI、難易度、数値整形を再利用する。
- すべての進行処理は「入力 → 中間状態 → 結果」の式を明示し、完全な乱数だけで結果を決めない。
- 乱数はイベント、天気、需要の小さな揺れに限定する。
- データ定義と計算処理を分け、項目を配列へ追加すれば拡張できる構造にする。

## ゲームループ

1. 状況を確認する
2. 価格・予算・配置・人員などを決める
3. 時間を進める
4. 複数要素の関係から結果を計算する
5. イベントへ対応し、次の判断を行う

## 保存

`worldia.save.v1.<mode>` にモード別保存、`worldia.meta.v1` に設定とチュートリアル状態を保存する。
